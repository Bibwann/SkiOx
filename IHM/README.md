# 🏔️ SkiOxAPP — Frontend Angular

Application Angular avec support **PWA** (installable sur mobile ou desktop).

---

## ✅ Prérequis

Assurez-vous d’avoir installé :

- **Node.js** (version recommandée : ≥ 18)  
  https://nodejs.org/
- **Angular CLI** (global)
```bash
npm install -g @angular/cli
````

Pour vérifier l’installation :

```bash
node -v
ng version
```

---

## 📥 Installation du projet

Dans un terminal, à la racine du projet :

```bash
npm install
```

---

## 🚀 Lancer l’application en développement

```bash
ng serve
```

Puis ouvrir dans le navigateur :

➡️ [http://localhost:4200/](http://localhost:4200/)

---

## 📦 Build Production (PWA activée)

Pour générer une version optimisée prête à être déployée :

```bash
ng build --configuration production
```

Le contenu généré se trouvera dans :

```
dist/skyOxIhm/browser/
```

---

## 📱 Tester le mode PWA en local

```bash
npx http-server ./dist/skyOxIhm/browser -p 8080
```

Puis ouvrir :

➡️ [http://localhost:8080/](http://localhost:8080/)

Vous pourrez alors **installer l’application** sur l’appareil (PC / Android / iOS).
